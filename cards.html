Card 0 · Setup

Claude Code + Playwright MCP

Two things to verify before we build. Takes 2 minutes.

Step 1 — Start Claude Code. Open your terminal and run:

claude

Step 2 — Install Playwright MCP. This gives Claude a real browser. Paste this into your terminal (not into Claude — into the terminal directly):

claude mcp add playwright -- npx @playwright/mcp@latest

Step 3 — Restart Claude Code, then verify it connected. Close Claude Code and reopen it with claude, then paste this inside Claude:

What MCP servers do you have connected? List them.
Ready when you see:
  • Claude lists playwright as a connected MCP server
  • It mentions browser tools like navigate, click, fill
Stuck on the MCP install? Raise your hand. The browser automation in Card 3 won't work without this. Don't skip it.

# Card 1 — Create Job Hunt Copilot

Create a skill called "job-hunt-copilot" at
~/.claude/skills/job-hunt-copilot/SKILL.md

The skill has four phases. Bake all of them into SKILL.md.

── PHASE 1 · INTAKE (runs once, everything saved to memory) ──────

On first run, collect and save to memory:
  - Resume (paste or file path) → memory/job-hunt-resume.md
  - Target role types            → memory/job-hunt-prefs.md
  - Industries of interest
  - Preferred geography
  - Company preferences (blacklist, whitelist, size preference)
  - LinkedIn profile URL          → memory/job-hunt-linkedin.md
  - Message style (or leave blank — skill writes one from resume)

Never re-ask for anything already saved in memory.

── PHASE 2 · DISCOVERY (triggered by "find me roles" or similar) ──

Using saved preferences:
1. Search LinkedIn Jobs, Glassdoor, company career pages, and web
   for matching roles posted in the last 14 days.
2. Filter by: geography, role type, and company preferences.
3. Skip any role already in tracker.xlsx.
4. Target 8–12 results per run.
5. For each role:
   a. Identify the best person to connect with at that company
      (hiring manager or team member). Search LinkedIn and the web.
      Save name + LinkedIn URL if found.
   b. Draft a cold email (under 120 words, role-specific, company-specific).
   c. Draft a LinkedIn connection message (under 280 characters, not
      "I'm job hunting" — one genuine reason to connect).
6. Save to ~/claude-outputs/job-hunt/pipeline-{YYYY-MM-DD}.csv
   Columns: Company | Role | Location | Posted | Apply URL |
   Apply Method | Match Reason | Contact Name | Contact LinkedIn URL |
   Cold Email Draft | LinkedIn Message | Status
   Apply Method = Portal / LinkedIn Easy Apply / Email
   Status = Pending (user changes to Apply / Skip / Hold)
7. Update tracker.xlsx with new rows (Status = Pending).
8. Show a summary table: Company | Role | Location | Match Reason
9. Say: "CSV saved. Open it, mark the roles you want as Apply, then
   tell me 'execute' to start applying."

── PHASE 3 · EXECUTE (triggered by "execute" or "apply now") ──────

Read the most recent pipeline CSV. For every row where Status = Apply:

Portal roles (Apply Method = Portal):
  1. Use Playwright to open the Apply URL in a visible browser.
  2. Pre-fill all standard fields from saved profile:
     name, email, phone, LinkedIn URL, resume.
  3. Use the cold email draft as cover letter text.
  4. For non-standard fields (essays, salary, "why this company"):
     STOP — show the question — wait for my answer — then continue.
  5. When all fields are filled: scroll to Submit, highlight it, STOP.
     Say: "Ready — please review and click Submit yourself."
  6. NEVER click Submit automatically. Ever.

LinkedIn connection (if Contact LinkedIn URL was found):
  1. Use Playwright to open the contact's LinkedIn profile URL.
  2. Click Connect → Add a note.
  3. Pre-fill the LinkedIn Message from the CSV.
  4. Show me the staged message and ask: "Send this connection request?"
  5. If I say yes — click Send.
  6. If I say no or ask for edits — update the message and ask again.

After I confirm each action:
  - Update tracker.xlsx: Status = Applied, Date = today
  - Add follow-up note: Follow up by {today + 5 days}

Process one role at a time. Ask before moving to the next.

── RATE LIMIT RULES (always enforced) ──────────────────────────────
- Max 20–25 LinkedIn connection requests per day
- Max 50 cold emails per day (warmed inbox)
- Max 10 portal applications per session
- If daily limit would be exceeded: warn me and stop

── OUTPUT RULES (always enforced) ───────────────────────────────────
- All outputs are files. Nothing important lives only in chat.
- Outputs folder: ~/claude-outputs/job-hunt/
- Tracker: ~/claude-outputs/job-hunt/tracker.xlsx
- Never guess facts. If uncertain, omit.
- Never claim experience not on my resume.

Write SKILL.md with frontmatter: name, description, when_to_use.
Print the full SKILL.md when done.
Done when:
  • Claude prints the full SKILL.md
  • You can see all four phases in the body
  • Frontmatter has name, description, and when_to_use
Read SKILL.md. It's 80–100 lines. Reading it is the whole lesson about how skills work — the card you just pasted taught Claude a job. Every card after this is just using what you built.

  • Filters by geography, work auth, freshness
  • Researches a contact at each company
  • Drafts a cold email + LinkedIn message per role

After all sub-agents complete:
- Merge into one pipeline CSV: ~/claude-outputs/job-hunt/batch-{date}.csv

# Card 7 — Build Meeting Prep Copilot

Create a skill called "meeting-prep" at
~/.claude/skills/meeting-prep/SKILL.md

Inputs:
- Calendar invite pasted as text
- Path to a .ics file
- Attendees + subject + date typed directly

For each meeting, produce a one-page brief:
1. Attendee profiles — title, company, public background,
   one memorable detail per person. Search LinkedIn and the web.
2. Company context — what they do, recent news, funding, competitors
3. Likely agenda — inferred from subject and attendee mix
4. Five smart questions to ask
5. Three things to have ready before the meeting
6. Open items check — any follow-ups from previous meetings
   with these people (from memory)

Memory pattern (same as Job Hunt Copilot):
- First run: ask for my role, company, and focus areas. Save. Never re-ask.
- Maintain a frequent-attendees file — reuse research, don't repeat searches.
- Save my format preference (default: executive bullets, max 1 page).

Output:
~/claude-outputs/meeting-prep/{date}-{subject-slug}.md
Always a file. Never just a chat reply.

Trigger phrase: "prep me for" + any meeting description

Rules: bullets not paragraphs, max 1 page, say "limited public info"
rather than guess on an attendee.

Write SKILL.md with proper frontmatter. Print it when done.
Done when:
  • ~/.claude/skills/meeting-prep/SKILL.md exists
  • Try it: say "prep me for a call with [name] at [company] on [date]"
  • A brief lands in ~/claude-outputs/meeting-prep/
Notice the shape. Skill folder. Intake saved to memory. Outputs as files. Tone preference. You built Job Hunt Copilot and Meeting Prep Copilot with the same pattern. Once you own the pattern, you can build anything you do twice a week.
